# Business Entity Resolution Pipeline

This repository contains a full, end-to-end Machine Learning pipeline for the Amazon ML Challenge: Business Entity Resolution task. It resolves businesses from Source 1 against databases in Source 2 and Source 3.

## Setup

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Place Data**:
   Ensure your TSV files are placed in the `data/` folder exactly as follows:
   - `data/train/train_source1.tsv`
   - `data/train/train_source2.tsv`
   - `data/train/train_source3.tsv`
   - `data/train/train_ground_truth.tsv`
   - `data/test/test_source1.tsv`
   - `data/test/test_source2.tsv`
   - `data/test/test_source3.tsv`

## Execution

Run the end-to-end pipeline using:
```bash
python src/pipeline.py
```

### Pipeline Flow:
1. **Ingestion & Validation**: Loads data robustly, checking for schema completeness and ID prefixes.
2. **Preprocessing**: Normalizes business names and addresses (lowercasing, punctuation stripping, abbreviation expansion).
3. **Validation Split**: Isolates 20% of `source1` entities for threshold tuning so we don't overfit.
4. **Candidate Generation (Blocking)**: Unions exact matches and token-based matches, deduplicating to ensure high recall without computationally exploding candidate pairs.
5. **Feature Engineering**: Computes pair-wise similarities (Edit distance, Jaccard token overlap) and country matching.
6. **Modeling**: Trains a `RandomForestClassifier` on the train split using true matches and *hard negatives* generated by the blockers.
7. **Threshold Tuning**: Learns the optimal decision boundary exclusively on the holdout validation set, maximizing the F0.5 score.
8. **Test Inference**: Applies the same pipeline logic to the `test/` dataset.
9. **Output Formatting**: Generates `matching_results.tsv` handling singletons (empty match lists) and removes duplicates, satisfying the challenge constraints.

## Outputs
Outputs will be written to:
- `output/candidate_pairs.tsv`
- `output/matching_results.tsv`
